# Gun & Parry

斜め見下ろし 3D の銃×パリィ・サバイバーズライク（ローグライト）。Unity 6000.5 / URP / Input System。

## 遊び方

15 分生き延び、最終ボス「COLOSSUS」を倒すとクリア（10:00 に中ボス「WARDEN」）。射撃は照準方向へ自動連射。

- **COLOSSUS（最終ボス）**: 装甲中は銃ダメージ 90% カット。パリィ由来の攻撃で装甲ゲージを削り、0 にすると 6.5 秒ブレイク（全ダメージ 2.5 倍）。
  - 装甲を削る手段: 反射弾（6）/ PERFECT 反射（12）/ カウンター弾（6）/ ハンマー叩きつけを着弾の瞬間にパリィ（30、PERFECT 45）/ パリィで吹き飛ばしたボマーを当てる（20）。6 秒パリィしないと装甲が回復する。
  - 攻撃: 扇状の弾幕（パリィ可）、ハンマー叩きつけ（赤円の予告→着弾）、薙ぎ払いレーザー（パリィ不可・ダッシュで抜ける）、金色弾（PERFECT でしか弾けない）、ボマー召喚。HP 66% / 33% でフェーズ移行して加速。

| 操作 | キーボード＋マウス | ゲームパッド |
|---|---|---|
| 移動 | WASD / 矢印 | 左スティック |
| 照準 | マウス | 右スティック（未入力なら最寄りの敵へ自動照準） |
| パリィ | 右クリック / Space | RB / RT |
| ダッシュ | 左クリック / Shift | A / LB / LT |
| ポーズ | Esc | Start |

- **パリィ**: 0.2 秒間無敵になり、範囲内の敵弾（ピンク）を強化して反射、近接敵はスタン＋ノックバック。弾を反射すると CD が 0.35 秒に短縮。赤い八面体の弾はパリィ不可。
  - **PERFECT**: 足元の金リング（1.5m）まで引きつけてから弾くと、反射弾2倍・全貫通・スロー・ゲージ2倍。
  - **空振り**: 何も弾けないと 0.4 秒鈍足。
  - **カウンター弾**: パリィ成功で金色の炸裂弾を装填（通常+2 / PERFECT+2 / BREAK+2、最大6）。ブラスターが自動で撃ち出す。
  - **BREAK**: Brute と近接エリートは赤く光って地面に赤いレーンを出してから突進する。突進の瞬間にパリィすると最大HPの60%（エリート25%）＋長スタン＋ゴールド。
  - **武器進化**: 武器 Lv7（MAX）＋指定パッシブで進化（レベルアップ時に必ず提示、宝箱では優先）。Reflector（Blaster+Mirror Coat）/ Nova Burst（Scatter+Counter Nova）/ Guardian Drones（Drones+Leech Parry）/ Counter Rail（Railgun+Reflex）/ Overdrive Swarm（Missiles+Overclock）/ Arc Aegis（Tesla+Armor）。
- **オーバードライブ**: パリィでゲージが溜まり、満タンで 6 秒間連射速度 2 倍＋貫通。
- **ボマー**: パリィすると吹き飛び、敵に当たって爆発する。
- レベルアップで武器 6 種 / パッシブ 14 種から選択（各 5 スロット）。エリートは宝箱（サプライキャッシュ）を落とす。
- **キャッシュ開封**: ゲームは止まらずスロー＆無敵の中で開封。ランク Standard(1) / Rare(2, 20%) / Prime(3, 6%)。報酬のデータ片が周回→1つずつ吸収され右側にカード表示。画面が暗転し自機の上に「PARRY!」の的が出る。縮む金リングが白い的に重なった瞬間（NOW!）にパリィで +1（失敗してもペナルティなし）。
- ラン終了時のゴールドで **Armory**（永続強化 10 種）を購入。

## セットアップ / ビルド

1. `Assets/Game/Scenes/Main.unity` を開いて Play。
2. 素材テンプレートやシーンを作り直す場合: メニュー **Gun & Parry > Setup Project**（何度実行しても同じ結果）。
3. Windows ビルド: Unity Hub で **Windows Build Support (Mono)** を追加後、**Gun & Parry > Build Windows (Steam)** → `Builds/Windows/`。

SE の試聴: **Gun & Parry > Export SFX Preview** → `SfxPreview/*.wav`。

開発ビルド／エディタ限定キー: F1 +1分, F2 レベルアップ, F3 無敵, F4 ボス直前へ, F5 +1000G, F6 オートパイロット, F7 ボス戦練習。

**ボス戦練習**（開発ビルド限定）: タイトルの **BOSS PRACTICE (DEV)** またはプレイ中に F7。15:00 相当のビルド（5武器・Reflector進化）と終盤の雑魚90体で COLOSSUS 戦から開始。報酬・戦績は保存されず、RETRY は練習のまま再開。

## 構成

コードのみでワールドと UI を構築する（シーンには `Game` コンポーネント 1 つだけ）。

| ファイル | 役割 |
|---|---|
| `GameData.cs` | 敵・武器・パッシブ・メタ強化・ウェーブの全数値（バランス調整はここだけ） |
| `Game.cs` | エントリポイント、状態遷移、更新順序、シミュレーション時計 `Game.Now` |
| `Player.cs` / `Weapons.cs` / `Projectiles.cs` | 自機・パリィ・武器・弾（スウィープ判定） |
| `Enemies.cs` / `Spawner.cs` / `Pickups.cs` | 敵 AI・ボス 3 フェーズ・空間ハッシュ・出現・ドロップ |
| `Upgrades.cs` / `SaveSystem.cs` | ステータス計算・抽選・セーブ（`persistentDataPath/save.json`、アトミック書き込み） |
| `Art.cs` / `Fx.cs` | プロシージャルなメッシュ・テクスチャ・パーティクル |
| `SynthKit.cs` / `SfxBank.cs` / `Sfx.cs` | 合成エンジン（帯域制限OSC・SVF・FM・リバーブ）、全SEのパッチ定義、再生と BGM |
| `UI.cs` / `UIKit.cs` | HUD とすべての画面（uGUI をコード生成） |

テスト: Test Runner の EditMode（`Assets/Game/Tests`）。

## 製品リリースまでに残っていること

- Steamworks 連携（Steamworks.NET、実績、Steam Cloud は `save.json` のフォルダを指定）
- アート・サウンドの差し替え（`Art` のメッシュ生成、`Sfx.Override` で個別に差し替え可能）
- ローカライズ（現在 UI は英語。日本語にはフォントアセットが必要）、キーコンフィグ
- 実プレイでのバランス調整（現状の数値はオートパイロットによる検証のみ）
